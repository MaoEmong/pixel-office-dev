# 로컬 기본·선택 원격 접속

픽셀 오피스의 기본 사용에는 계정·도메인·Tailscale 설치가 필요 없다.
작업은 PC에서 진행·저장된다. http://127.0.0.1:7423 은 그 PC의 브라우저에서만 열린다.
모바일이나 다른 PC의 localhost는 작업 PC를 뜻하지 않는다.

외출 중 접속할 사용자만 Tailscale을 설정한다. 프로젝트는 개발자 도메인이나
개발자가 운영하는 중계 서버를 제공하지 않는다. Tailscale은 별도 서비스이며 사용자는
현재 요금제·조건을 확인한다. 앱은 Tailscale 설치·로그인·서비스 공개를 자동 실행하지 않는다.

## 권장: 내 Tailscale 네트워크에서 접속

1. 작업 PC와 휴대폰/다른 PC에 [Tailscale](https://tailscale.com/download)을 설치하고 같은 tailnet에 연결한다.
2. 픽셀 오피스를 실행하고 PC 터미널에서 `tailscale serve --bg http://127.0.0.1:7423`을 실행한다.
   포트를 변경했다면 앱 기기 연결 화면의 로컬 주소를 사용한다.
3. 출력된 HTTPS 주소를 앱 상단 ⋮ → 기기 연결·원격 조작 → 외부 접속 설정에 저장한다.
4. QR/키를 만들고 연결 기기에서 등록을 요청한 뒤 PC에서 이름·지문을 확인해 승인한다.

Serve는 tailnet 안에서만 접근된다. 기기 승인도 별도로 필요하다.
중단은 `tailscale serve --https=443 off`. 다른 Serve 설정이 있다면 먼저
`tailscale serve status`로 확인한다. 해당 HTTPS listener에 적용되는 명령이다.
[공식 Serve 문서](https://tailscale.com/docs/reference/tailscale-cli/serve)

## 선택: 휴대폰에 Tailscale 없이 브라우저 접속

작업 PC에서 `tailscale funnel --bg http://127.0.0.1:7423`을 사용한다.
출력된 HTTPS 주소 저장과 QR 등록 절차는 동일하다. PC의 Tailscale 계정·HTTPS 설정과
Funnel 권한이 필요하며, 처음에는 Tailscale에서 활성화 절차를 안내할 수 있다.
Funnel은 인터넷에 접속 경로를 공개한다. 미승인 기기는 작업 데이터를 볼 수 없지만
등록 페이지는 인터넷에서 접근할 수 있다. 의도적으로 이 방식을 선택한 사용자만 실행한다.
중단은 `tailscale funnel --https=443 off`, 확인은 `tailscale funnel status`.
[공식 Funnel 문서](https://tailscale.com/docs/features/tailscale-funnel)

## 로컬로 복귀와 인증 유지

앱의 '로컬 주소로 돌아가기'는 접속 주소와 허용 origin을 초기화한다.
Tailscale 서비스는 별도로 종료한다. 기존 공개키 등록은 자동 삭제되지 않는다.
기기 접근을 폐기하려면 '연결 해제'를 사용한다.
같은 HTTPS 주소·브라우저 데이터를 유지하면 등록 인증을 재사용한다.
주소 변경·브라우저 데이터 삭제 뒤에는 다시 등록한다.
PC가 켜져 있고 데몬이 실행 중이어야 외출 중 조작할 수 있다.
7420 RPC·7421 hook·7422 MCP는 외부에 연결하지 않고 7423 gateway만 전달한다.
