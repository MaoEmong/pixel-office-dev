## D-01 · 2026-09-14 · 연동 방식: 실제 CLI TUI를 pty로 띄운다
- 맥락: rev 1 설계는 Agent SDK / codex app-server 프로그램 연동.
- 결정: `claude` / `codex` 인터랙티브 CLI를 node-pty에 그대로 띄우고 타이핑으로 지시한다. 상태는 hooks로.
- 버린 대안: Agent SDK(별도 크레딧·터미널 없음), app-server, hooks만(지시 불가).
- 근거: 사용자 의도("그냥 cli를 켜서 거기다 명령"), 구독 그대로 사용, 터미널 화면 공짜. 실측 02 전 항목 통과.

## D-02 · 2026-09-14 · 데몬은 Flutter와 분리된 상주 프로세스
- 맥락: 자식 프로세스(A) vs 상주 데몬(C).
- 결정: localhost WebSocket 데몬. 앱을 꺼도 세션 유지, 나중에 모바일 클라이언트.
- 근거: 사용자 "밖에서 모바일앱으로 작업 진행시키고 싶다".

## D-03 · 2026-09-14 · hook 명령은 Node 스크립트 하나로, 멤버 식별은 환경변수
- 맥락: curl.exe는 Claude(bash)에선 되고 Codex에선 exit 1.
- 결정: `node <슬래시경로>/hook.js <event>` 공통. 스폰 시 `PIXEL_MEMBER` env 주입 → hook이 상속 → URL `/hook/<token>/<event>`.
- 버린 대안: 세션별 settings에 토큰을 박는 방식(Codex는 cwd 단위 hooks.json이라 팀원 간 공유돼 불가).
- 근거: 02 ④ 프로브 결과.

## D-04 · 2026-09-14 · 허가·질문은 hook 결정 반환으로, 키 입력은 다이얼로그 통과 전용
- 결정: `PermissionRequest` hook 응답(`decision.behavior`, `updatedInput.answers`)으로 TUI 프롬프트를 대체. 키 입력(↓, Enter)은 온보딩·폴더 신뢰 다이얼로그에만.
- 근거: 02 ②③④ 실측. TUI 키 매핑 의존을 최소화.
