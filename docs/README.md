## 한 줄 요약

캐릭터 하나 = 실제 `claude` / `codex` CLI 세션 하나. 상주 데몬이 CLI를 가상 터미널에 띄우고, hooks로 상태를 받고, 지시는 터미널에 타이핑한다. Flutter 픽셀아트 사무실에서 관전·지시·허가·보고. 조직은 **부서 → 부장 → 팀장 → 팀원** 3단 트리(rev 3, D-32): 내가 만드는 것은 **부서(=프로젝트 폴더)와 부장**뿐이고, 부장이 팀을 만들어 팀장을 배치하고 팀장이 팀원을 고용한다. 지시는 부장에게만, 보고·질문은 한 칸씩 위로. 나는 셸 허가와 멤버별 지시문, 그리고 비상시 퇴근으로 개입한다.
