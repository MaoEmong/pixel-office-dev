## 요지 (Fable 정리)

- **[critical] 플랜 §3 이 비어 있다** — 상태·규모·여정·스프라이트 규격이 "부실" 이 아니라 0줄. §3 을 채우기 전 APPROVED 불가.
- **정보 위계**: 실제 시선 순서가 패널 글자 → 허가 카드 → 사무실(3등). 부장 앵커 없음(D3 에서 큰 방을 버리고 대체물 미지정 → 금색 카펫 + 왕관으로). 서열 `허가 카드 > 내 책상 대기 수 > 부장 > 클러스터 > 로그/터미널` 을 명시. 보고서 타이포 미다룸(12px 고정폭 벽글 → 가변폭 14px/1.6, 6줄 클램프).
- **상태**: 코드 상태 13종(`office_scene.dart`) vs 범례 6칸 → 매핑표 필수. `visitorSpot` 이 점 하나라 동시 `ask_parent` 2명이 겹침. `queueSlot` 상한 없음(6번째부터 책상 밖). 로딩 3종(데몬 부팅·멤버 starting·resume 복구) 미기재. 허가 카드에 hook 만료 카운트다운 없음. 빈 상태 3종에 그림 없음(1명 팀 클러스터가 전폭 빈 상자).
- **규모**: 4팀@1280×720 필요 높이 1266 vs 가용 584 → scale 0.46(하한 0.45) 경계, 5팀부터 내 책상 밑으로. 1920×1080 도 6팀에서 같은 일. 1명 팀도 상자 전폭. 2560 에서 상한 1.0 이라 섬. 터미널 80열 ≈ 660px 패널 ↔ 사무실 900px 충돌 미언급. → 세로 스크롤 + 내 책상 바닥 고정 바, 상자 폭 = min(n,4) 열, 상한 1.5·5열, 패널 드래그 420~720 + 터미널 탭 자동 확장.
- **여정**: 첫 화면이 스택 트레이스(T39-8 — 예외 문자열이 책상 위를 가로지름, 하드리젝션). 부장 임명 직후 3~10초 빈 화면. 첫 허가 명령 6줄 줄바꿈 뒤범벅.
