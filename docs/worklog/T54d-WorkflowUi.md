# T54d — 대화·회의·검수 화면

하단 입력을 workflow.discuss로 연결하고 명시적인 회의 시작 버튼을 추가했다.
회의 다이얼로그에 공유 작업안, 대화, 참석자별 두 차례 발언, 부장 결정,
팀별 완료 기준·선행 담당·진행 상태, 최종 보고를 표시한다.
검수 완료·취소·누락 의견 재개 버튼과 재접속 후 조회를 구현했다.
활성 회의·실행 중 하단 입력을 비활성화하여 별도 구현 task를 만들지 않는다.
참석자 이름은 회의에 저장해 팀 정리 뒤에도 읽을 수 있다.

검증: flutter analyze 통과, Flutter 전체 746개 통과(기존 1개 skip).
위젯 검증: 대화와 시작 RPC 분리, 실행 중 입력 잠금, 검수 완료, 퇴근 참석자 이름 표시.
GUI에서 두 차례 발언·의존성 대기·Write 허가·최종 보고·검수 완료까지 확인.
Windows release 빌드와 최종 GUI 재기동은 T54g에서 마무리한다.
