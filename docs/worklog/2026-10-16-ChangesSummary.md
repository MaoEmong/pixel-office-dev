# 픽셀 오피스 개선 내용 정리 (2026-10-16)

부서 생성 오류 안내를 추가한 커밋 `6af4640` 이후 진행한 작업을 정리한다.

## 사용자가 확인할 수 있는 변화

### 문제가 생기면 팝업으로 안내

- 부서·멤버·대화·회의 조작, 승인·질문 응답, 터미널 연결, 원격 기기 관리, 설정 저장에서 실패 원인을 팝업으로 표시한다.
- 앱을 다시 열었을 때 이미 발생한 오류도 안내한다. 해결 전까지 경고를 남기고, 실제 문제가 해결되면 해제한다.
- 로그인 만료 등 AI 실행 오류에서 해당 멤버의 터미널로 바로 이동할 수 있다.

### 사용할 AI와 실제 진행 상황 표시

- Claude만 사용, Codex만 사용, 둘 다 사용 설정을 상단에 표시하고 부서 생성에도 적용한다.
- Codex 계정에서 실제로 사용할 수 있는 모델을 확인해 지원하지 않는 모델 때문에 실행이 막히는 문제를 줄였다.
- 회의 안건, 참석자별 발언, 1·2차 의견 제출, 계획 확정, 담당 업무와 대기 이유를 구분해 보여 준다.

### 작업 중에도 부장과 대화하고 회의를 복구

- 회의·업무 진행·중단·검수 중에도 부장에게 질문과 변경 지시를 보낼 수 있다.
- 추가 질문의 답변과 업무 완료 보고를 구분해, 대화 때문에 진행 중인 작업이 완료 처리되지 않도록 했다.
- 부장이 현재 부서의 실제 멤버 목록을 확인하고 내부 참석자 연결을 복구할 수 있다. 기존 회의 의견과 작업안은 유지한다.

### 대화·회의·작업 계획을 읽기 쉽게 구분

- 대화, 회의, 작업 계획을 별도 탭으로 나누고 작성자·시간·상태가 있는 카드로 표시한다.
- 제목, 강조, 목록, 표, 인용, 코드 표시와 내용 복사를 제공한다.
- 항목을 접었다 펼칠 때 본문이 회색으로 사라지는 문제를 수정했다.
- 창을 열어 둔 상태에서도 최신 대화와 진행 상태가 갱신된다. 예전 대화를 읽고 있다면 위치를 유지하고 ‘새 대화 보기’를 표시한다.
- 늦게 도착한 조회 결과가 새 상태를 덮지 않게 하고, 작성 중인 질문도 유지한다.

### 터미널 로그인 공유와 앱 안에서의 로그인

- 터미널과 앱 세션 사이에 유효한 로그인 정보를 반영하고 갱신을 공유한다. 설정과 대화 기록은 프로젝트별로 유지한다.
- 로그인 만료 시 아직 처리하지 못한 요청을 보관한다. 로그인 복구 후 같은 대화에서 요청을 다시 처리할 수 있다.
- 앱의 터미널에 실제 로그인 프로그램을 여는 버튼, 로그인 연결·요청 재시도 버튼, `/help` 같은 명령 입력란을 추가했다.
- 인증 정보 자체는 Git, 이벤트, 팝업이나 작업 기록에 담지 않는다.

- 앱 코드 검사 문제 없음. 전체 검사 **831건 통과·1건 건너뜀**.
- Windows 실행 파일 생성 성공.
- 커밋 전 검사에서 로그인·복구 버튼 검사가 이전 처리 완료를 기다린 뒤 다음 버튼을 누르도록 보완했다.
- 실제 앱에서 기존 회의 연결 복구, 로그인 연결 복구와 멈췄던 부장 요청의 답변 완료를 확인했다.
- 화면만 수정한 경우 작업 관리 프로그램과 AI 세션을 유지한 채 적용했다.
- 이번 실행 확인 환경은 Windows다. 다른 운영체제에서의 실행과 새 로그인 과정의 브라우저 계정 승인은 자동 검사에 포함하지 않았다.
