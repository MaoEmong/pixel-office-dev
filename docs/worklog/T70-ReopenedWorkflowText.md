# T70 — 접었다 펼친 본문이 사라지는 문제

## 원인과 수정

- 공유 작업안을 펼치는 검사에서 `type 'bool' is not a subtype of type 'double?'` 오류를 재현했다. 배포된 앱에서는 이 오류가 난 본문이 회색 영역으로 표시됐다.
- 펼침 여부와 선택 가능한 본문의 내부 스크롤 위치가 같은 저장 공간을 사용했다. 공유 작업안에는 목록 위치와 구분되는 저장 이름도 없었다.
- 본문은 `SelectionArea`와 일반 Markdown 표시를 조합해 글자 선택을 유지하면서 불필요한 내부 스크롤 저장을 없앴다. 공유 작업안의 펼침 상태에도 별도 저장 이름을 부여했다.

## 확인 범위

- 공유 작업안과 회의 차수를 각각 세 번 접었다 펼치고, 펼치는 도중에도 본문 오류가 없는지 검사한다.
- 탭 전환, 작업안 갱신, 작성 중인 질문 보존, 글자 선택 후 복사와 원문 전체 복사를 검사한다.
- 수정 전 새 검사가 실패하고 수정 후 통과하는 것을 확인했다.
- 앱 코드 검사 문제 없음. 전체 검사 824건 통과·1건 건너뜀. Windows 실행 파일 생성 성공.
- 실행 중인 작업 관리 프로그램 PID 11124를 유지한 채 화면 프로그램만 교체했다.
