# T55g — PC·원격 브라우저 직접 조작

최신 Windows release 앱을 실행한 상태에서 computer-use로 상단 메뉴를 열어 QR/키를 만들었다.
Codex 브라우저에서 GUI 테스트 기기로 등록을 요청했다. 양쪽의 같은 공개키 지문을 확인하고
PC의 기기 승인 버튼을 눌렀다. 브라우저가 자동 연결됐고 reload 뒤에도 등록을 재사용했다.

브라우저에서 부장에게 remote-gui.txt / REMOTE_GUI_OK 작업안을 보냈다.
작업 시작·회의 소집을 눌러 Claude 팀장 두 명의 4개 회의 의견과 업무 배정을 확인했다.
Write 승인 카드가 표시된 시점에 파일이 없음을 PC에서 확인하고 브라우저 허가를 눌렀다.
작성·Read 검토 뒤 최종 보고를 확인해 검수 완료를 눌렀다. 파일 내용은 REMOTE_GUI_OK였다.
reload 뒤 검수 완료가 복구되었다. 390px 폭에 가로 넘침이 없었다.

PC 앱에서 연결 해제를 눌렀다. 등록 기기가 사라졌고 브라우저도 해제 안내·등록 화면으로 돌아왔다.
숨겨진 작업 화면도 비워졌으며 reload 뒤에도 기기 등록이 필요했다. 테스트 기기는 남기지 않았다.
PC 앱은 사무실 화면으로 돌려두고 브라우저의 임시 viewport를 해제했다.

증빙: img/T55-remote-report.png, img/T55-remote-revoked.png.
Cloudflare Tunnel·구매 도메인·실제 외출망 연결은 사용자 요청대로 이번에는 설정하지 않았다.
그 연결 전 현재 주소는 이 PC에서만 사용할 수 있는 로컬 테스트 주소다.
