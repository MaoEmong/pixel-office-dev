# T72 — 대화 창을 닫지 않아도 최신 내용 반영

## 원인

- 최신 답변이 길면 본문 시작을 보여 주기 위한 스크롤 위치가 0보다 커진다. 기존 코드는 이 위치를 예전 대화를 읽는 것으로 판단해 새 답변으로 이동하지 않았다. 새 답변이 짧으면 화면 밖에 남았다.
- 상태 조회 응답과 실시간 변경 알림의 순서를 구분하지 않아, 늦게 도착한 과거 조회 결과가 새 대화·회의 상태를 덮을 수 있었다.

## 수정

- 실제 최신 답변의 읽기 위치를 기준으로 새 답변을 따라간다. 예전 기록을 읽고 있을 때는 그 위치를 유지하고 ‘새 대화 보기’를 표시한다.
- 조회 중 최신 변경 알림이 오면 이전 조회 결과와 오류를 적용하지 않는다. 여러 조회가 겹쳐도 마지막 조회만 적용한다.
- 부장 응답 종료 때도 상태를 다시 확인해 실시간 알림을 놓친 경우 내용을 보완한다.

## 검사

- 창을 열어 둔 채 대화를 두 번 보내고 답변을 받는 과정과 회의 시작·진행 변경을 검사했다.
- 긴 답변 이후 짧은 답변의 표시, 과거 기록 위치 보존과 새 대화 이동을 검사했다.
- 최신 알림 뒤 과거 조회 결과를 도착시켜 수정 전 상태가 되돌아가던 문제를 재현했다. 수정 후 최신 내용이 유지된다.
- 응답 종료로 누락된 변경을 반영하고 작성 중인 질문이 유지되는지 검사했다.
- 앱 코드 검사 문제 없음. 전체 검사 831건 통과·1건 건너뜀. Windows 실행 파일 생성 성공.
- 작업 관리 프로그램 PID 6412와 AI 세션을 유지하고 화면 프로그램만 교체했다. 진행 중인 업무·승인 대기는 그대로다.
