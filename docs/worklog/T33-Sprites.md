## 목표

T40a 가 남긴 두 줄 — "캐릭터는 아직 원이다", "범례·배지의 📨 ⏳ ♛ 가 두부다" — 를 지운다.
끝나면 사무실의 사람과 소품이 **32×32 픽셀 스프라이트**로 그려지고(포즈 8종 + 걷기, 정수 배율),

## 한 것

### 1. 에셋 — 아틀라스 생성기 + 서체 3종 (`d3cddb9`)

`assets/sprites/characters.png` **256×96 = 32×32 셀 8열 × 3줄**을 `tool/gen_sprites.dart` 가 만든다
(순수 Dart, 의존성 0 — zlib 위에 PNG 인코더까지 직접).

| 줄 | 열 0..7 |
|---|---|
| 0 | idle · type1 · type2 · think · alert · ask · report · error |
| 1 | 걷기 왼쪽 0..3 · 오른쪽 0..3(왼쪽의 **좌우 반전**) |
| 2 | 왕관 16×16 · 별 12×12 · 의자 16×18 + 봉투 · 모래시계 · 경고 · 느낌표 · 물음표(**흰 실루엣**) |

- 몸·머리·팔·다리를 **같은 함수**로 그리고 포즈는 인자만 바꾼다. 외곽선은 실루엣에서 **자동 생성**
  (투명 픽셀 중 그림에 닿은 곳) — 포즈마다 손으로 찍지 않으니 프레임 간 굵기가 어긋날 수가 없다.
- `--preview=<path> --zoom=8 --bg=1B1F2A` 확대본, `--bounds` 로 소품의 실제 경계를 찍는다
  (그 값이 `SpriteProp.inCell` 상수이고, 테스트가 실제 PNG 와 대조한다).
- 서체: Galmuri11 v2.40.4 · Pretendard v1.3.9(Regular/Bold) · D2Coding VER1.3.3 — 전부 OFL 1.1,
  전문 3개 동봉. 출처·버전·라이선스는 `dev/app/assets/LICENSES.md`.

### 2. 서체 배선 + 두부 글자 정리 (`c712d71`)

- 캔버스 = **Galmuri11**(페인터 기본값), 패널·상단 바 = **Pretendard**(`ThemeData.fontFamily`),
  고정폭 = **D2Coding**. 폴백은 **번들 서체를 먼저** 둔다.
- 캔버스 글자 크기 14곳을 `officeFontPx()` 로 **정수 반올림** — 픽셀 서체는 정수 크기에서만 또렷하다.
- 세 서체 어디에도 없는 이모지 교체: `📨`→`✉` · `⏳`→`◷` · `📖`→`◫` · `📋`·`📄`→`▤` · `💬`→`❝`.
- `test/office/office_fonts_test.dart`(10건) — 배선·정수 크기·FontManifest·OFL 전문 +
  **글자 허용 목록**(앱 문구에서 기호를 긁어 모아 번들 서체에 있는 것만 쓰는지 본다).

### 3. 원 → 스프라이트 (`1f5d475`)

`lib/office/office_sprites.dart` 가 아틀라스의 단일 창구다(매핑·프레임 계산은 전부 순수 함수).

- **포즈**: `spritePoseOf(SceneMember, visiting:)`. 입력이 상태 어휘의 단일 기준 **`LegendSlot`** 이라
  링 색과 포즈가 같은 곳에서 갈라진다 — 13상태 → 8포즈 매핑이 범례와 어긋날 수가 없다.
- **애니메이션**: 타이핑 2프레임 0.5초. 걷기는 시간이 아니라 **걸어온 거리**(14px/프레임) —
  짧게 옮기면 한두 프레임, 길게 걸으면 발이 여러 번 구른다. 방향은 출발→도착 dx 부호.
- **정수 배율**: `spriteScale`(scale ≥ 0.75 → 2, 아니면 1) × 32px, `alignSpriteRect` 으로 정수 자리,
  `FilterQuality.none` + `isAntiAlias: false`.
- **외형**: 아틀라스의 교체 키 4색(셔츠 `#FF00FF`·`#C000C0`, 머리 `#00FFFF`·`#00C0C0`)을 불러올 때
  픽셀 한 판으로 바꿔 **엔진 2 × 머리색 4 = 8벌** 캐시. 이름 해시는 FNV-1a.
- **소품**: 왕관(책상 위 앵커 + 직급 배지) · 별 · 의자 · 범례 아이콘 4종
  (흰 실루엣 + `ColorFilter.srcIn` 으로 범례 색 — 캔버스는 글자가 아니라 그림을 쓴다).
- **안전망**: `sprites == null` 이면 예전 원 + 머리글자. 에셋을 읽는 첫 프레임과 미리보기·기존
  위젯 테스트가 그 경로라 사무실이 한 프레임도 비지 않는다.
- **T40 편차 ⑥ 해소**: 슬롯 대기자·보고 방문자의 말풍선 꼬리를 `OfficeLayout.barBubbleY`
  (내 책상 상자 **위**)로 올렸다.
- 히트 테스트·시맨틱 API 는 **한 줄도 안 바꿨다** — T40b 패널 코드와 기존 테스트가 그대로 돈다.

## 발견한 함정

1. **`testWidgets` 안에서 `dart:io` 를 `await` 하면 영영 안 끝난다.** OFL 전문을 읽는 테스트가 가짜 시계 존에
   갇혀 8분 뒤 `did not complete` 로 죽었다(에러도 아니고 그냥 멈춘다). 파일은 `test()` + `readAsStringSync()`.
2. **시스템 서체 폴백은 근거가 아니다.** 편차 ⑤ 의 `📨`(U+1F4E8)·`⏳`(U+23F3)·`♛`(U+265B) 는 Segoe UI Emoji /
   Symbol 에 있는데도 두부였다. 반면 `❗`(U+2757)는 나왔다 — **어느 글자가 폴백을 타는지 예측할 수 없다**.
   그래서 세 서체의 cmap 을 직접 읽어 확인하고, 폴백 목록에 **번들 서체를 먼저** 넣고, 허용 목록 테스트로 못 박았다.
3. **링을 스프라이트 가운데에 두면 머리 옆으로 삐져나온다.** 원(지름 ≈26px)일 때는 딱 맞던 링이, 세로로 길고
   머리가 좁은 스프라이트에서는 은색 옷깃처럼 보였다(팀장 은색 링에서 발견 — 단위 테스트로는 절대 안 잡힌다).
   링 중심을 **발치**로 내려 "바닥에 놓인 상태 표시" 로 만들었다.
4. **흰 실루엣 아이콘은 투명 배경 위에서 안 보인다.** 생성기 확대본을 그냥 보고 "아이콘이 깨졌다" 고 오진했다.
   미리보기에 `--bg` 를 넣고 나서야 멀쩡한 것을 확인했다. 아이콘을 고칠 때는 배경을 깔고 봐야 한다.
5. **캡처 스크립트의 `-Out` 은 상대 경로만 받는다**(`Join-Path (Get-Location) $Out`). 절대 경로를 주면
   조용히 실패하면서 "saved=" 만 빈 채로 찍힌다 — 버스트 40장을 통째로 날렸다.
6. **`AsyncValue.valueOrNull` 은 riverpod 3 에 없다** — `.value` 가 nullable 이다.
7. **`SpriteSheet.single`(테스트용)은 같은 이미지를 8자리에 꽂는다** — `dispose()` 가 같은 `ui.Image` 를
   여덟 번 버리면 디버그에서 터진다. 신원(identity)으로 한 번씩만 버린다.

## 결정 (04 에 새로 적을 것은 **한 건**)

**D-43 4 에서 벗어난 것 — Kenney CC0 팩을 쓰지 못했다.**
1순위였던 "Kenney 16×16 캐릭터를 2× 로 쓰고 포즈는 직접 편집"이 성립하지 않았다. 실제로 받아 확인했다:
- **Roguelike Characters 2.0**(CC0, 450칸): 정면 서 있는 **1포즈짜리 paperdoll**(몸 + 투구·갑옷·무기 레이어).
  앉음·타이핑·생각·보고·오류 포즈도, **걷기 프레임도 없다**.
- **Tiny Town**(CC0, 130칸): 캐릭터가 아예 없다(지형·건물 타일). 의자·책상 소품도 없다.
- Micro Roguelike / 1-Bit Pack: 같은 이유(1포즈) + 해상도·색 수가 사무실 화면과 안 맞는다.

D-43 2 가 요구하는 것은 **포즈 8종 + 걷기 4프레임**이라 "직접 편집" 이 사실상 전부 새로 그리는 일이 된다.
그래서 **손으로 쓴 픽셀 좌표를 코드로 찍는 방식**(`tool/gen_sprites.dart`)으로 그렸다.
**AI 이미지 생성이 아니다** — 결정론적 도형 코드이므로 D-43 4 의 "AI 생성 스프라이트 금지"(프레임 간 일관성·
라이선스 불명)에 걸리지 않고, 오히려 그 조항이 걱정한 프레임 일관성은 코드가 보장한다(같은 함수 + 자동 외곽선 +
걷기 오른쪽 = 왼쪽의 반전). 저작권은 이 저장소 산출물이므로 **CC0 1.0**. 나머지 D-43 항목(1 CustomPainter 유지,
2 셀·포즈·프레임, 3 정수 배율, 5 외형)은 그대로 지켰다.

사양이 딱 떨어지지 않아 **가장 가까운 쪽으로 고른 것** 넷:
1. **범례·직급 아이콘은 글자가 아니라 그림**. 패스 4 는 "아이콘은 범례 7칸의 ❗⏳📨⚠ 넷 + 왕관·별" 이라고만
   했다. 캔버스에서는 서체 의존을 없애려고 아틀라스 아이콘을 쓰고, 글자 아이콘(`LegendSlot.icon`)은 캔버스 밖
   (오른쪽 패널)의 몫으로 남겼다.
2. **상태 링은 발치로**(위 함정 3). 색·굵기·점선 여부는 문서 그대로다.
3. **아틀라스 한 장 + 런타임 색 교체**(pre-bake 8장이 아니라). 8벌 ≈ 786KB 메모리, 저장소에는 1.5KB PNG 하나.
   포즈를 고칠 때 8장을 다시 만들 필요가 없다.
4. **`gone` 포즈는 칸을 쓰지 않는다**. D-43 2 는 포즈 8종에 `gone` 을 넣었지만 퇴근은 "의자만" 이라 캐릭터를
   그리지 않는다 — 열 8개는 idle·type1·type2·think·alert·ask·report·error 가 쓴다(type 이 2칸).

## 남은 것

- **터미널 주 서체는 아직 Cascadia Mono.** `panelMonoFamily` 가 `lib/panel/labels.dart`(T40d 소관)에 있어
  건드리지 않았다. **한 줄이면 된다**: `const String panelMonoFamily = 'D2Coding';`.
  지금도 폴백 목록에 `D2Coding` 이 있어 **한글은 이미 D2Coding 으로 떨어진다**(Cascadia Mono·Consolas 에 한글이
  없다) — 라틴 글자만 Cascadia Mono 다. 코디네이터가 판단할 것.
- **지시 바 칩 `♛ <부장>에게`·카드의 `❗`** 는 `lib/command/**`·`lib/panel/**` 에 글자로 있는데, 이번 테마 폴백
  (`[D2Coding, Galmuri11, Malgun Gothic]`)으로 **두부가 풀렸다**(실기 캡처 03·08 에서 확인). 문자열은 안 건드렸다.
- **T40a 함정 ③(스크롤 중 걷는 캐릭터가 두 좌표계를 가로지른다)은 그대로 둔다.** 스프라이트로 바꾼 뒤에도
  실기에서 거슬릴 만큼은 아니었다(정지 상태는 언제나 정확, 이번 부서는 스크롤이 생길 규모가 아니었다).
  8명 이상 + 스크롤이 생기는 화면에서 다시 볼 것.
- **포즈가 부족하면 8종에 append**(D-43 결과 문구 그대로). 지금 아쉬운 것은 "셸 락 대기" 와 "출근 중" 이
  둘 다 idle 로 떨어지는 것 — 말풍선·모니터·링 색으로는 구분되지만 포즈로는 안 된다.
