# T54b — 작업 흐름 영속 저장

목표: 구체화 대화, 회의 차례·발언, 계획·업무, 결과를 재시작 후에도 유지한다.

한 것: Workflow 타입과 기존 SQLite의 workflows 테이블, 현재 작업 조회·저장·이력 조회를 추가.
부서 삭제 시 외래 키로 작업 흐름 이력도 정리한다. 기존 데이터베이스 버전과 테이블은 유지.

검증: `npm run typecheck`, `node --import tsx --test test/store/workflow.test.ts` 통과.
기존 DB 재열기·발언 복원·새 작업 조회·부서 삭제 연동 1개 시나리오 통과.

발견한 함정: 기존 schema 테이블 재생성에 영향을 주지 않도록 migrate 완료 뒤 추가 테이블을 생성.

결정: 회의 상태 전체를 JSON으로 원자적으로 저장해 발언·차례의 부분 갱신을 피한다.

남은 것: T54c 회의 진행과 프로젝트 작업안 내보내기.
