# T69 — 대화·회의 팝업 가독성

## 변경

- 대화, 회의, 작업 계획을 별도 탭으로 나누고 각각 기록 개수를 표시한다. 공유 작업안은 작업 계획 탭에서 펼쳐 볼 수 있다.
- 사용자 요청과 부장 답변을 배경·테두리·아이콘·작성자·시간이 있는 카드로 구분한다. 줄 간격과 본문 크기를 늘렸다.
- 제목, 강조, 목록, 표, 인용, 코드 서식을 표시한다. 긴 답변도 작성자와 본문 시작이 먼저 보이도록 위치를 맞춘다.
- ‘최근 대화’ 버튼과 메시지별 전체 내용 복사를 제공한다. 원본 대화는 바꾸지 않는다.
- 회의 의견은 1차·2차로 묶고, 각 의견의 작성자·시간과 부장의 회의 결정을 구분한다.
- 작업 계획은 팀별 업무, 진행 상태, 완료 기준, 선행 담당과 최종 보고를 구분한다.
- 탭을 바꾸거나 상태가 새로 들어와도 작성 중인 질문은 유지한다. 기존 대화 전송·회의 재개·작업 취소 동작을 유지한다.

## 확인

- 긴 답변의 작성자·본문 시작 노출, 실제 서식·표 렌더링, 전체 원문 복사를 검사했다.
- 대화·회의·작업 탭 전환, 차수별 회의 기록, 새 답변 반영, 작성 중인 질문 유지, 680×560 창에서의 배치를 검사했다.
- 기존 작업 시작·진행 중 메시지·검수 완료·복구 버튼·답변 상태 검사도 통과했다.
- 앱 코드 검사 문제 없음. 전체 검사 823건 통과·1건 건너뜀. Windows 실행 파일 생성 성공.
- 실행 중인 작업 관리 프로그램 PID 11124를 유지하고 화면 프로그램만 교체했다. AI 작업을 중단하거나 회의를 재시작하지 않았다.
