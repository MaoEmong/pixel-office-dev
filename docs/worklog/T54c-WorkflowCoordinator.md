# T54c — 회의 진행과 실행 제어

구체화, 회의 두 차례, 부장 결정, 실행, 검수 대기, 완료/막힘/취소 단계와 RPC를 구현했다.
참석자 직급·부서·생존, 차례 중복, 모든 팀장 업무, 완료 기준과 의존성 순환을 검증한다.
회의 완료 전 Write/수정/실행 도구는 PreToolUse와 PermissionRequest에서 거부한다.
확정 계획의 선행 작업이 done으로 보고되어야 후속 팀장에게 배정한다.
조기 부장 보고와 idle 보고 폴백은 회의 단계에서 거부하며 최종 전문을 저장한다.
정상 종료와 참석자 오류를 구분하고 회의 재개는 누락 의견만 요청한다.

검증: typecheck와 Workflow.test.ts 5개 통과. 실제 Claude 회의→Write 승인→후속 검토→
부장 보고→정상 종료→동일 sessionId 복원→검수 완료 통과(244초).
보고 이벤트를 알린 뒤 후속 위임을 발행하여 이벤트 seq 역전도 해결했다.
프로젝트 .pixel-office/workflows/<id>.json 내보내기 확인.
