# T55d — PC 기기 연결 화면

상단 메뉴에 기기 연결·원격 조작 다이얼로그를 추가했다.
QR/키/링크 발급·복사, 만료 표시, 요청 기기 이름·지문 확인, 승인·거부·해제,
등록 기기 목록, 이후 외부 HTTPS 주소 설정, 기존 계속 일하기 설정을 연결했다.
도메인 연결 전 로컬 주소라는 사실을 화면에 표시한다.
검증: Flutter analyze와 기존 전체 746개 통과. 추가 widget 테스트는 T55f에서 전체 재검사한다.
기기 리스트는 로컬 인증 RPC만 호출하고 공개 web에 관리자 키를 전달하지 않는다.
다음: T55e 브라우저 화면·기기 키 영속 저장.
