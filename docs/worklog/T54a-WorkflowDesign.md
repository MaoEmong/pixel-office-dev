# T54a — 회의 작업 흐름 설계

목표: 사용자와 부장의 구체화 대화, 팀 회의, 계획에 따른 실행을 기존 직급 구조에 연결한다.

한 것: 기존 MCP 직급·위임·보고·hooks·SQLite·Flutter 지시 구조를 확인하고
`docs/design/회의-작업흐름.md`에 상태, 도구, 검증 기준을 정했다.

검증: 기존 구현에서 회의 단계가 없고 모든 지시가 일반 task로 즉시 배정됨을 확인.

결정: 두 차례 의견 교환, 명시적 시작, 계획 확정 전 구현 차단, 기존 작업·보고 사슬 재사용.

남은 것: T54b~T54g.
