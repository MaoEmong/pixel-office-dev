# T56 — 공개 연결 안내와 README 정리

README의 최신 상태와 원격 접속 절차를 갱신하고 docs 색인에 텍스트/HTML 안내서를 연결했다.
개인 로컬 HTML에서 PC 주소가 표시된 설정 캡처와 개인 주소를 제외한 공개 안내서를 만들었다.
직접 캡처한 사무실·메뉴·브라우저 등록 화면 3장은 단일 HTML에 포함했다.
개인 안내서와 캡처 원본은 ignored .local에 유지하고 계정·주소·등록 키를 공개 자료에 넣지 않았다.
모바일 폭 브라우저 검사와 실제 휴대폰 외부망 확인을 구분해 기록했다.
검증: HTML 이미지·확대·레이아웃은 앞선 동일 안내서에서 확인했고 공개본의 이미지 수,
개인 주소 제외, README의 로컬 상대 링크와 git diff --check를 확인했다.
