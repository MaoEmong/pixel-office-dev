## ② hooks 주입·페이로드

- [x] `--settings <json>` 세션 단위 hooks 주입 — **된다.** 전역 settings.json의 hooks와 **병합**됨(전역 Stop hook + 세션 Stop hook = "Ran 2 stop hooks"). 전역은 안 건드림.
- [x] `SessionStart` 페이로드 — `session_id, transcript_path, cwd, scratchpad_dir, hook_event_name, source("startup"), model`
- [x] `PreToolUse` — `tool_name, tool_input, tool_use_id, permission_mode, effort, prompt_id`. `PostToolUse` — 추가로 `tool_response, duration_ms`. **실패 시 `PostToolUse`는 안 오고 `PostToolUseFailure`가 온다**(`cat nofile.txt` 실측) → 셸 뮤텍스 해제는 `PostToolUse` + `PostToolUseFailure` 둘 다에서. 읽기 전용 명령(`cat`)은 `default` 모드에서도 `PermissionRequest` 없이 실행됨 → 뮤텍스는 `PreToolUse` 기준으로 잡아야 함(허가 여부와 무관). `SubagentStop`도 등록 시 Stop 직후 한 번 옴(서브에이전트 없어도).
- [x] `PermissionRequest` hook 결정 반환 — **TUI 프롬프트를 대체한다.** 3초 보류 후 `{"hookSpecificOutput":{"hookEventName":"PermissionRequest","decision":{"behavior":"allow"}}}` 반환 → 화면에 "Allowed by PermissionRequest hook". 페이로드에 `permission_suggestions` 포함.
- [x] hook `timeout` — settings에 `timeout: 600` 두고 **PermissionRequest를 75초 보류해도 정상 allow됨**(기본 60초를 넘김). 보류 6초 시점에 `Notification` hook(허가 대기 알림)이 따로 옴. 상한은 더 큰 값(예: 86400)으로 M0에서 재확인.
- [x] `Stop` 페이로드 — **`last_assistant_message` 있음**, `stop_hook_active, background_tasks, session_crons`도.
- [x] hook 명령 셸 — **`/usr/bin/bash`(git bash)로 실행됨.** Windows 경로(`C:\...`)는 백슬래시가 먹혀 실패 → POSIX 경로(`/c/Windows/System32/curl.exe`) 사용. 왕복 지연: PreToolUse→PermissionRequest 간격 ~150ms 수준(curl 기동 포함, 체감 무해).
- [x] `UserPromptSubmit` — `prompt, prompt_id, permission_mode`. `SessionEnd` — `reason`.
