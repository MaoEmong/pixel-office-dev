# 로그인 없는 기기 연결 (T55)

작업 PC가 공개키 기반으로 원격 기기를 승인한다. 계정과 클라우드 데이터베이스는 없다.
PC의 remote-devices.db에 workstation ID, 공개 접속 URL, 기기 공개키·이름·승인/해제 상태를 보관한다.
브라우저는 origin별 IndexedDB에 export 불가능한 ECDSA P-256 개인키와 기기 ID만 저장한다.
작업 스냅샷·대화·로그·회의·보고는 메모리에서만 표시하며 Cache-Control:no-store로 전송한다.

## 등록과 인증

PC 로컬 인증 RPC에서 5분 유효·1회용 256bit 키/QR을 발급한다.
QR URL fragment에 키를 넣어 HTTP 요청·referrer에 남기지 않는다. 키는 PC에서 해시만 보관한다.
브라우저는 자체 키쌍을 만들고 연결 키·공개키·기기 이름으로 등록 요청한다.
PC에서 이름과 공개키 지문을 확인한 뒤 승인/거부한다. 요청 전에는 작업 데이터 접근 불가.
기기 서명으로 소유를 확인하고, 승인 뒤에는 socket별 30초 challenge 응답으로 자동 인증한다.
nonce 재사용·다른 PC identity·다른 socket proof를 거부한다. 무인증 등록/인증에는 제한을 둔다.
등록은 자동 만료되지 않는다. PC 재시작·브라우저 새로고침 후 같은 키로 접속한다.
브라우저 데이터 삭제·다른 origin 접속은 새 기기로 다시 등록해야 한다.

## 연결 해제

PC 또는 원격 기기에서 해당 등록을 해제할 수 있다. PC에서 revoked를 먼저 영속 저장하고
연결된 socket/내부 RPC 연결을 닫아 즉시 차단한다. 승인/해제된 키는 다시 등록 요청해도 재사용 불가.
원격이 오프라인이면 개인키를 삭제하고 서버에 해제할 서명 요청(tombstone)만 저장한다.
다음 접속에서 먼저 해제 요청을 전달한 뒤 삭제한다. PC는 오프라인 중 해제를 알 수 없으며
PC 화면에는 동기화 전까지 등록이 남는다. 로컬 브라우저에서는 해제 즉시 사용할 수 없다.

## 통신과 범위

HTTP/WebSocket gateway는 기본 loopback 7423. 이후 Cloudflare Tunnel → HTTPS/WSS로 연결한다.
외부 origin은 PC에 설정한 HTTPS URL과 정확히 일치해야 한다. Host·Origin 검사와 CSP를 적용한다.
기존 7420 RPC·7421 hook·7422 MCP·로컬 관리 token은 외부에 노출하지 않는다.
외부 socket은 허용된 업무 RPC만 내부 연결로 전달한다. parentPid·force·daemon 종료·기기 관리자 RPC는 전달하지 않는다.
원격 화면: 부서 선택, 사무실 상태, 부장 대화/회의 시작·재개·취소·검수, 승인·질문 답변, 회의록·보고·로그.
프로젝트/부서 생성은 이번 화면에서는 PC에서 수행한다. 작업 폴더와 파일은 항상 PC에 있다.
등록된 PC마다 각 접속 주소로 들어간다. 주소별 기기 등록을 독립적으로 유지한다.
외부 도메인/Cloudflare 계정 연결과 휴대폰 실기 접속은 사용자가 나중으로 미룬 범위다.

## 검증

만료/중복/거부/승인 전 정보 차단, 잘못된 서명/nonce 재사용, 재시작 후 키 유지,
PC·기기 해제 시 재접속 거부, offline tombstone, Origin/Host 차단, 관리자 RPC 차단,
여러 기기 승인 경합, 브라우저 작업 데이터 미저장, 모바일 폭·QR 생성, 실 작업 승인·보고.
