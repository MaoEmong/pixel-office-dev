## 3. 리뷰 패스

외부 의견(Opus 5 서브에이전트, 단일 모델 — Codex 는 D-23 한도)은 `worklog/T32-outside-voice-opus.md`. 하드리젝션 2건(보고서 카드 스택 · 오버레이 예외 문자열)은 패스 4 에서, 나머지는 해당 패스의 선행 항목.

### 패스 1 — 정보 구조 (시작 4/10)

**시선 서열(확정, D5=1A):** `허가 카드 > 내 책상 대기 수 > 부장 > 팀 클러스터 > 로그·터미널`. 화면 어느 요소든 이 서열보다 위로 올라가면 안 된다 — 아래 모든 결정의 기준.

**부장 앵커(확정, D5=1A):** 책상 크기는 일반과 같다(D3). 대신 **바닥과 관**으로 구별한다 — 부장 책상 아래 금색 카펫(책상 Rect 사방 +20px, `#FFD166` 알파 0.12, 모서리 4px), 책상 위 가운데 왕관 스프라이트 16×16(T33), 캐릭터 링 금색은 유지. 팀장은 카펫 없이 은색 별(현행).

```
┌ 상단 바: [폴더] 부서탭… │ 선택 멤버 │ 데몬 pill │ 멤버 N·대기 N │ [부서 만들기] ⋮ ┐
├──────────────── 사무실(왼쪽, 나머지 폭) ────────────────┬── 오른쪽 패널 ──┤
│  문     ┌─금색 카펫─┐                                   │ 헤더(아바타·이름·엔진·상태·트리 줄·cwd)
│  │      │  부장 책상 │ ← 서열 3                          │ ▶ 허가/질문 대기 블록 (전역, 서열 1)
│         └──────────┘                                    │ 탭: 로그 │ 터미널 │ 지시문 │ 보고서
│  ┌ 팀 카펫 A ── 팀장★ 팀원 팀원 팀원 ┐  ← 서열 4          │
│  ┌ 팀 카펫 B ── 팀장★ 팀원 ┐                             │
│  …(세로 스크롤, 패스 6)                                   │
│  [내 책상 · 대기 N] 슬롯 ○ ○ ◌ ◌   ← 서열 2 (바닥 고정)   │
│  범례: ●작업 ●한가 ●대기 ●보고대기 ●오류 ●퇴근              │
├──────────── 지시 바: 부장에게 │ 입력 │ 중단 │ 전송 ────────┴─────────────────┤
```

**pending 의 주인은 하나(확정, D6=2A):** 오른쪽 패널 헤더 바로 아래 **"내 책상 · 대기 N" 블록**이 사용자 몫 pending(`Pending.goesToUser` — 허가 전부 + 부장 `ask_user` + TUI 질문) 전부를 **선택 멤버와 무관하게** 오래된 순서로 보여 준다(`PendingInbox` 배선). 카드 2개까지 펼치고 3개째부터는 접힌 목록 "+N" (클릭하면 펼침). 사무실 내 책상의 슬롯·배지는 같은 목록의 그림이다 — 슬롯 클릭 = 그 멤버 선택 + 인박스에서 그 카드로 스크롤. 카드에 답하면 양쪽에서 동시에 사라진다. 선택 멤버의 `ask_parent` 안내 카드("대신 답하기")는 사용자 몫이 아니므로 지금처럼 그 멤버 패널(인박스 아래, 탭 위)에만.

**글자 빼기(확정, D7=3A):** 책상 라벨은 **이름(굵게) + 직급 배지 + 엔진 배지**만 — "책상 N ·" 접두어 삭제(번호는 툴팁·로그에만). 축소 시 숨기는 순서: 엔진 배지 → 직급 배지 글자(아이콘만) → 이름은 마지막까지(말줄임). 지시 바의 드롭다운은 **정적 칩 "♛ <부장이름>에게"** 로 교체(부장 없으면 회색 "부장 없음" + 입력 비활성); 부서 전환은 상단 탭이 한다.

**패스 1 재평가: 9/10** — 서열·앵커·pending 주인·글자 빼기가 확정. 남은 1점은 보고서 탭 타이포(패스 4 하드리젝션에서 다룸).

### 패스 2 — 상태 커버리지 (시작 3/10)

코드에는 상태 어휘 13종이 이미 있는데(`office_scene.dart`: starting · working(reading/editing/running/thinking) · idle · free · waiting_reports · waiting_approval · waiting_answer · ask_parent 방문 · delegating · reporting · exited · error · 셸 락 대기) 플랜에는 상태 명세가 0줄이고 범례는 6칸이다.

**상태 → 범례 7칸 매핑(확정, D8=4A).** 이 표가 캐릭터 링 색 · 하단 범례 · 패널 헤더 상태 점 · T33 포즈의 **단일 기준**이다.

| 범례 칸 | 색 | 아이콘 | 포함하는 코드 상태 | 사용자가 할 일 |
|---|---|---|---|---|
| 작업 | 파랑 `#6C8EFF` (현행 charWorking) | — | working(reading·editing·running·thinking) · delegating · reporting | 없음 |
| 한가 | 초록 `#7ED3A1` (charIdle) | — | idle · free | 지시 가능(부장만) |
| 보고 대기 | 초록 **점선** 링 | 📨 | waiting_reports (부하 보고를 기다림) | 없음 |
| **내 차례** | 주황 `#FF9F43` (신규) | ❗ | waiting_approval · 부장 `ask_user` · TUI AskUserQuestion | **답해야 한다** — 내 책상 슬롯에 선다 |
| 대기 | 노랑 `#FFC857` (charWaiting) | ⏳ | `ask_parent` 답 대기(상사 책상 옆) · 셸 락 대기 · starting(출근 중) | 없음 |
| 오류 | 빨강 `#FF6B6B` (charError) + 책상 테두리 빨강 | ⚠ | error(비정상 종료) | 재고용 배너 |
| 퇴근 | 회색 `#474D5E` (charGone), 의자만 | — | exited | 없음 |

범례는 사무실 캔버스 맨 아래 한 줄(높이 24px, 글자 11px, 점 8px)로 항상 보인다. 색 점 = 캐릭터 링 색과 동일.

**같은 자리에 여러 명(확정, D9=5A):**
- 내 책상 = 인박스 그림. 안쪽에 **슬롯 4칸 고정**(빈 슬롯은 점선 실루엣), 오래된 것부터 왼쪽. 5명째부터는 캐릭터가 자기 책상에 남고(링 주황 ❗) 맨 오른쪽 슬롯 위 배지 **"+N"**. 배지 클릭 = 인박스 펼침(D6). 헤더 "내 책상 · 대기 N" 의 N 은 전체 수.
- 상사 책상 옆(`ask_parent`): `visitorSpot(deskIndex, k)` — k 번째는 오른쪽으로 `2r + 8px` 씩, **최대 2명** 표시, 3명째부터 두 번째 자리 위 "+N" 말풍선. 책상이 화면 오른쪽 끝(다음 자리가 `size.width - r - 2` 를 넘으면)이면 왼쪽 옆으로 접는다.

**로딩 3종 + 만료(확정, D10=6A):**
- 데몬 pill 3상태: 초록 `● 데몬 v1.0 · pid N` / 노랑 점멸(1Hz) `◌ 연결 중 · N초` / 빨강 `● 끊김 · 재시도 N회`. 끊김 오버레이는 같은 문구 + 다음 재시도까지의 진행 바(재접속 백오프 주기). 예외 문자열은 **"자세히" 접힘**(패스 4 하드리젝션 ②).
- 멤버 `starting`: 문이 열리고 캐릭터가 책상까지 **1.2초** 걸어가 앉는다(기존 `office_motion` 경로 재사용). 모니터 `(출근 중)` + 노란 링(대기 칸). 프롬프트 준비(`isPromptReady`)되면 초록.
- 복구(`[RESUMED]`): 복구된 멤버는 책상 테두리 **점선 3초** + 말풍선 `↻ 복구됨`. 복구로 만료된 허가는 인박스에 회색 **"만료 — 재지시"** 카드(현행 redo 카드가 인박스 안으로 들어온다).
- 허가·질문 카드 오른쪽 위 메타: `요청 2분 전 · 내일 10:32 만료`(hook 보류 상한 86400초 기준). 만료 1시간 전부터 메타 글자 초록 → 주황. 만료되면 카드가 회색 "만료 — 재지시" 로 바뀐다.

**빈 상태 3종 + 퇴근 누적(확정, D11=7A):**
- 부서 0개: 빈 바닥 + 문만. 가운데 큰 버튼 **"부서 만들기"**(상단 버튼과 같은 다이얼로그) + 한 줄 "프로젝트 폴더 하나 = 부서 하나. 부장이 팀을 꾸립니다." 회색 격자 위 문구 한 줄로 끝내지 않는다.
- 부장만(팀 0): 부장 카펫 아래 **점선 클러스터 자리 하나** "팀은 부장이 만듭니다 — 아래 지시 바에 첫 지시를". 지시 바 placeholder 는 예시 문장 "예: 이 저장소 구조를 파악해서 보고해".
- 클러스터 상자 폭 = `min(인원, 4)` 열 폭 + inset, **왼쪽 정렬** (1명 팀이 전폭 빈 상자가 되지 않게). 같은 줄에 두 클러스터가 들어가면 나란히 놓는다(패스 6 규모).
