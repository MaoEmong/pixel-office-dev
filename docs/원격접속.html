Tailscale Serve가 출력한 자신의 HTTPS 주소를 사용하세요.

PC 앱과 브라우저 화면 3장을 직접 캡처한 공개용 안내서입니다. 모바일 설치·LTE/5G 접속·모바일 조작은 아직 확인하지 않았습니다. QR과 유효한 등록 키는 포함하지 않았으며 등록할 때 새로 발급합니다.

픽셀 오피스의 기본 사용에는 계정·도메인·Tailscale 설치가 필요 없다.

작업은 PC에서 진행·저장된다. http://127.0.0.1:7423 은 그 PC의 브라우저에서만 열린다.

모바일이나 다른 PC의 localhost는 작업 PC를 뜻하지 않는다.

외출 중 접속할 사용자만 Tailscale을 설정한다. 프로젝트는 개발자 도메인이나

개발자가 운영하는 중계 서버를 제공하지 않는다. Tailscale은 별도 서비스이며 사용자는

현재 요금제·조건을 확인한다. 앱은 Tailscale 설치·로그인·서비스 공개를 자동 실행하지 않는다.

권장: 내 Tailscale 네트워크에서 접속

Tailscale 로그인은 기기들이 같은 개인 네트워크에 들어가기 위한 설정이다.

픽셀 오피스의 계정을 만드는 과정은 아니다. 네트워크 연결과 픽셀 오피스 기기 승인은

서로 다른 절차이며 둘 다 완료해야 작업을 조작할 수 있다.

  1. 작업 PC와 휴대폰/다른 PC에 Tailscale ↗을 설치하고 같은 tailnet에 연결한다.
  2. 픽셀 오피스를 실행하고 PC 터미널에서 tailscale serve --bg http://127.0.0.1:7423을 실행한다.

포트를 변경했다면 앱 기기 연결 화면의 로컬 주소를 사용한다.

  1. 출력된 HTTPS 주소를 앱 상단 ⋮ → 기기 연결·원격 조작 → 외부 접속 설정에 저장한다.
  2. QR/키를 만들고 연결 기기에서 등록을 요청한 뒤 PC에서 이름·지문을 확인해 승인한다.

Serve는 tailnet 안에서만 접근된다. 기기 승인도 별도로 필요하다.

중단은 tailscale serve --https=443 off. 다른 Serve 설정이 있다면 먼저

tailscale serve status로 확인한다. 해당 HTTPS listener에 적용되는 명령이다.

PC 최초 설정 상세

  1. 공식 설치 파일로 Tailscale을 설치하고 Windows 관리자 권한 요청을 허용한다.
  2. Tailscale에서 로그인하고 사용할 계정에 PC를 연결한다.
  3. 픽셀 오피스의 데몬이 연결된 상태인지 확인한다. PC 브라우저에서

http://127.0.0.1:7423/을 열었을 때 기기 등록 화면이 나오면 gateway가 실행 중이다.

  1. 위 Serve 명령을 실행한다. 명령을 찾을 수 없는 Windows 환경에서는 다음처럼 실행한다.
   & 'C:\Program Files\Tailscale\tailscale.exe' serve --bg http://127.0.0.1:7423
  1. HTTPS 활성화 링크가 표시되면 연다. 선택 항목 Tailscale Funnel은 체크를 해제하고

HTTPS만 활성화한다. HTTPS 인증서 발급 시 PC의 DNS 이름은 공개 인증서 기록에 남는다.

이는 접속 경로를 인터넷에 공개하는 Funnel 활성화와는 별개다.

  1. 명령 출력의 https://<PC 이름>.<네트워크 이름>.ts.net/ 주소를 복사한다.

Available within your tailnet 또는 tailnet only가 표시되는지 확인한다.

  1. 앱의 상단 ⋮ → 기기 연결·원격 조작 → 외부 접속 설정 · 선택 (Tailscale)을 펼친다.

복사한 HTTPS 주소를 넣고 '접속 주소 저장'을 누른다. 별도의 도메인 구매는 필요 없다.

Android와 iPhone 연결

  1. Android는 Google Play, iPhone은 App Store에서 공식 Tailscale 앱을 설치한다.
  2. 앱을 열어 PC와 같은 계정으로 로그인하고 기기를 연결한다.

다른 계정·다른 개인 네트워크로 연결하면 이 PC에 접근할 수 없다.

  1. 운영체제가 VPN 연결/구성 추가를 요청하면 허용하고 Tailscale 연결을 켠다.
  2. 앱의 기기 목록에서 작업 PC가 보이는지 확인한다.
  3. 휴대폰의 일반 브라우저(Chrome/Safari)에서 PC의 HTTPS 주소를 연다.

PC의 로컬 주소 127.0.0.1이나 Tailscale IP의 HTTP 주소를 대신 입력하지 않는다.

설치 화면과 버튼 이름은 앱 버전에 따라 다를 수 있다.

픽셀 오피스 QR·연결 키 등록

  1. PC 앱의 기기 연결 화면에서 'QR · 연결 키 만들기'를 누른다.
  2. 휴대폰 카메라로 QR을 읽고 앞으로 계속 사용할 브라우저에서 링크를 연다.

앱 내부 임시 브라우저나 시크릿/개인정보 보호 창은 피한다.

  1. QR을 사용할 수 없으면 HTTPS 주소를 직접 열고 PC 화면의 연결 키를 복사해 입력한다.
  2. 기기 이름(예: 내 iPhone)을 입력하고 '등록 요청'을 누른다.
  3. PC의 '승인 대기'에 나온 이름과 지문이 휴대폰 화면과 같은지 확인한다.
  4. PC에서 '기기 승인'을 누른다. 휴대폰이 '연결됨'으로 바뀌고 사무실 화면이 나타나면 완료다.

연결 키는 발급 후 5분 동안 한 번만 사용할 수 있다. 만료되면 새로 발급한다.

등록 키의 만료와 이미 승인된 기기의 인증 유지는 별개다.

QR을 공유하는 대신 연결할 기기에서만 사용하고, 모르는 기기 요청은 승인하지 않는다.

외출 중 사용과 확인 순서

  1. 외출 전에 PC를 켜둔다. 절전·최대 절전·종료 상태에서는 조작할 수 없다.
  2. 픽셀 오피스를 실행해 데몬이 연결돼 있는지 확인한다.

앱 창을 닫고도 계속 사용할 때만 '앱을 닫아도 계속 일하기'를 켠다.

이 옵션은 PC 전원·절전이나 재부팅 후 앱 실행을 대신 관리하지 않는다.

  1. 휴대폰에서 Tailscale 연결을 켜고 등록했던 브라우저로 같은 HTTPS 주소에 접속한다.
  2. 승인된 기기는 자동 인증된다. 매번 QR을 스캔할 필요는 없다.
  3. 부서를 선택해 상태·회의록·보고를 보고, 부장 대화·작업 시작·승인·질문 답변·검수를 조작한다.

프로젝트 부서 생성은 현재 PC 앱에서 수행한다.

실제 외부망 확인은 휴대폰 Wi-Fi를 끄고 LTE/5G에서 접속해 진행한다.

첫 확인은 상태 조회와 새로고침부터 하고, 작업 요청은 테스트 부서에서 작은 작업으로 검증한다.

브라우저를 닫아도 PC 작업은 계속되며 다음 접속 때 PC 상태를 다시 읽는다.

다른 PC에서 연결

다른 PC에도 Tailscale을 설치하고 같은 네트워크에 연결한다.

브라우저에서 동일한 HTTPS 주소를 열어 기기 이름을 입력하고 새 QR/키로 등록한다.

각 브라우저는 별도 기기로 승인된다. 작업은 원래 작업 PC에서 실행·저장된다.

선택: 휴대폰에 Tailscale 없이 브라우저 접속

작업 PC에서 tailscale funnel --bg http://127.0.0.1:7423을 사용한다.

출력된 HTTPS 주소 저장과 QR 등록 절차는 동일하다. PC의 Tailscale 계정·HTTPS 설정과

Funnel 권한이 필요하며, 처음에는 Tailscale에서 활성화 절차를 안내할 수 있다.

Funnel은 인터넷에 접속 경로를 공개한다. 미승인 기기는 작업 데이터를 볼 수 없지만

등록 페이지는 인터넷에서 접근할 수 있다. 의도적으로 이 방식을 선택한 사용자만 실행한다.

중단은 tailscale funnel --https=443 off, 확인은 tailscale funnel status.

공식 Funnel 문서 ↗

로컬로 복귀와 인증 유지

앱의 '로컬 주소로 돌아가기'는 접속 주소와 허용 origin을 초기화한다.

Tailscale 서비스는 별도로 종료한다. 기존 공개키 등록은 자동 삭제되지 않는다.

기기 접근을 폐기하려면 '연결 해제'를 사용한다.

PC에서는 등록된 기기 옆 '연결 해제', 원격 브라우저에서는 '이 기기' → '이 기기 연결 해제' → 확인을 누른다.

휴대폰 Tailscale 연결을 끄는 것은 접속만 중단하며 픽셀 오피스 기기 등록을 삭제하지 않는다.

기기를 분실했다면 PC에서 해당 기기 등록을 해제하고 Tailscale 기기 관리에서도 접근을 제거한다.

원격 기기가 offline에서 등록을 해제하면 로컬 개인키는 즉시 삭제되고 PC에는 다음 연결 때 해제 사실이 전달된다.

같은 HTTPS 주소·브라우저 데이터를 유지하면 등록 인증을 재사용한다.

주소 변경·브라우저 데이터 삭제 뒤에는 다시 등록한다.

PC가 켜져 있고 데몬이 실행 중이어야 외출 중 조작할 수 있다.

7420 RPC·7421 hook·7422 MCP는 외부에 연결하지 않고 7423 gateway만 전달한다.

이미지가 포함된 단일 HTML 파일입니다. 외부 폰트·분석·스크립트를 사용하지 않습니다. 이미지 클릭 시 확대, Esc로 닫기.
